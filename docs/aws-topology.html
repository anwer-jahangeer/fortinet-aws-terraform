Traffic flows

Internet and licensing: FortiGate WAN -> AWS subnet gateway .1 -> Debian .254 -> SNAT/EIP -> AWS IGW.

Management: Administrator -> jumpbox EIP -> Windows jumpbox -> VPC local route -> FortiGate port1.

FortiManager Cloud: FortiGate -> Debian NAT -> Internet -> FortiManager Cloud on TCP/541.

Site traffic: Ubuntu LAN -> FortiGate -> ISP1, ISP2 or MPLS underlay -> remote FortiGate and LAN.

FortiGate WAN ENIs use private addresses only. Public EIPs terminate on Debian, which provides one-to-one circuit NAT and hairpin NAT for lab overlays.
